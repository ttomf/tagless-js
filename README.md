# Tagless JS

A simple webpage without using any HTML tag (except `<script>`) for [Tagless Hackclub event](https://tagless.hackclub.com/).

## How this works

Browser adds `<body>` tag even if it isn't in HTML file, so only written tag is `<script>`.

Whole page is just `<body>` with `white-space: pre` style, buffer is drawn on it. I use JetBrains Mono Nerd font because it has icons.

No generative AI was used to write anything in this project.
